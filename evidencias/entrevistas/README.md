# Evidências das entrevistas

**PENDENTE — coleta de dados reais com stakeholders.** Nenhuma resposta foi recebida nesta preparação.

Utilize o [roteiro](../../docs/03-elicitacao/roteiro-entrevistas.md), o [modelo CSV](modelo-registro.csv) e a [ficha de resultados](../../docs/03-elicitacao/resultados-entrevistas.md). O CSV contém apenas o cabeçalho de um instrumento, não uma coleta concluída.

Guarde registros identificáveis e autorizações fora do repositório público. Se for necessário usar armazenamento local neste projeto, `privado/` é ignorado pelo Git; isso não substitui controle de acesso nem impede inclusão forçada. Publique apenas sínteses anonimizadas revisadas pelo grupo. Não inclua nomes, matrículas, contatos, gravações ou diagnósticos dos entrevistados no repositório público.

Após uma entrevista real, registre código, perfil, data real, perguntas, respostas ou resumos fiéis, necessidades, requisitos e limites. Uma captura deve ser autêntica; não produzir imagens simulando entrevistas ou aceites.
