# Evidência obrigatória de acesso ao GitHub

1. Acesse o repositório como administrador.
2. Abra a área de configurações de acesso / colaboradores e adicione `marcelobezerra-dotcom`.
3. Salve print que mostre o nome convidado e o estado da solicitação, **sem divulgar tokens ou dados pessoais desnecessários**.
4. Coloque o print aqui como `convite-marcelobezerra-dotcom.png` (ou nome equivalente).
5. Registre no AVA a URL verdadeira do repositório.

A evidência não foi criada automaticamente: o grupo precisa realizar o convite em sua conta GitHub.
