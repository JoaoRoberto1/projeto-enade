## Ficha para cada entrevista real

Copiar esta ficha apenas quando houver aplicação. Campos abaixo são instruções de preenchimento, não uma entrevista cadastrada.

| Campo | Valor a preencher |
|---|---|
| Código e perfil | ENT-[sequencial] e ST-[perfil] |
| Data, duração e modalidade | Data/hora reais; presencial/remota |
| Entrevistador | Integrante responsável |
| Autorização para registro | Decisão real do participante e referência restrita, quando cabível |
| Objetivo e versão do roteiro | Tema investigado; versão aplicada |
| Pergunta | ID do [roteiro](roteiro-entrevistas.md) |
| Resposta | Transcrição autorizada ou resumo fiel, distinguindo ambos |
| Necessidade identificada | N existente ou novo candidato, com justificativa |
| Requisito relacionado | RF/RNF/RN existente, candidato novo ou sem relação identificada |
| Observações | Contexto, divergência, limite da interpretação |
| Evidência e validação do entendimento | Referência a registro anonimizado; retorno real do participante |

O [modelo CSV](../../evidencias/entrevistas/modelo-registro.csv) é um instrumento sem respostas. Após a coleta, produzir síntese por perfil e atualizar a matriz. A ausência de dados permanece visível no checklist até haver evidência real.
