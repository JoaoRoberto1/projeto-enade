# Roteiros de entrevistas semiestruturadas

**Instrumentos preparados — PENDENTE: coleta de dados reais com stakeholders.**

## Objetivo e protocolo comum

Investigar práticas reais, dificuldades, necessidades pedagógicas, simulados, organização de questões, feedback, acessibilidade e segurança. Começar com perguntas abertas e solicitar exemplos; não sugerir que as funcionalidades listadas já foram aprovadas. Consultar o [plano](planejamento-elicitacao.md).

Antes de cada aplicação, registrar: código da entrevista, perfil, data real, modalidade, entrevistador, autorização para registro e versão deste roteiro. Todos esses campos estão **PENDENTES** até a aplicação. Para cada pergunta, preencher resposta, necessidade identificada, requisito relacionado e observações; as associações abaixo são hipóteses de investigação, não achados.
