# Instruções para entrega no AVA

**Situação:** instruções preparadas; nenhuma submissão no AVA realizada nesta tarefa. O prazo histórico da M1 terminou em **01/11/2026**. Confirmar no AVA ou com o professor a situação de entrega fora desse período, sem alterar datas para aparentar pontualidade.

1. Preencher nomes e demais dados de identificação do grupo exigidos pela disciplina. Evitar publicar matrículas no repositório público quando puderem ser informadas somente no AVA.
2. Realizar ou incorporar entrevistas reais, analisar respostas e registrar validações. Não entregar modelos vazios como resultados empíricos.
3. Revisar o [checklist](checklist-entrega.md), os três diagramas e as divergências de escopo registradas em [referências](../../referencias/README.md).
4. Conferir a branch `docs/m1-requirements-and-uml` e o [estado de publicação](../../evidencias/github/README.md). URL real do repositório: [JoaoRoberto1/projeto-enade](https://github.com/JoaoRoberto1/projeto-enade).
5. Usar também o link direto da [branch documental](https://github.com/JoaoRoberto1/projeto-enade/tree/docs/m1-requirements-and-uml), para o avaliador localizar a versão sem depender da branch padrão.
6. Verificar o acesso de `marcelobezerra-dotcom`, distinguir convite pendente de colaboração aceita e guardar captura real se o formulário exigir imagem. A confirmação da API é uma evidência técnica, não um print.
7. Abrir a atividade correta no AVA, preencher o link verdadeiro e anexar somente os arquivos solicitados pelo formulário. Se exigido PDF, usar a versão atual complementar em [entregáveis](../../entregaveis/README.md), não o PDF histórico preservado.
8. Revisar o conteúdo enviado e finalizar a submissão no AVA. Guardar o comprovante real em local apropriado, sem divulgar dados acadêmicos pessoais desnecessários.

O formato exato do formulário, seus campos e a política de atraso não foram acessados. Essas informações precisam ser conferidas pelo grupo. Publicação no GitHub não equivale a submissão no AVA.
