# Trilha ENADE — protótipo P2

Protótipo navegável em HTML, CSS e JavaScript, com contas e questões fictícias. Documento completo em [docs/11-prototipos](../docs/11-prototipos/README.md).

Executar na raiz: `python -m http.server 8765 --directory prototipo`.

Abrir `http://localhost:8765`. Para wireframes: `http://localhost:8765/wireframes.html`.

Não há backend. Dados ficam no localStorage do navegador; perfis, senha demonstrativa e permissões são simulações. A aplicação-alvo e os limites de fidelidade estão no SRS. A senha de demonstração é `enade2026`.
